
# Portfolio 5: Distributed and Cloud Database Exercise

## Project
**Case study:** ExpressMall E-Commerce — an online perfume store.

## Objective
This portfolio examines how distributed and cloud database concepts can help ExpressMall improve availability, scalability, reliability, and data consistency.

## Business Challenge
As ExpressMall grows, a single database server may become a performance bottleneck or a point of failure. The business needs to consider how to maintain access to its data and manage increasing orders safely.

## Concepts Covered
- **Cloud databases:** hosting database services on cloud infrastructure.
- **Replication:** maintaining copies of data on multiple database nodes.
- **Sharding:** dividing a large dataset across multiple database servers.
- **Availability and recovery:** planning for server failures and service interruptions.
- **Consistency:** protecting data integrity, especially perfume stock quantities.
- **Security:** controlling database access and protecting connection credentials.

## Folder Structure
- `docs/` — case study and supporting documentation.
- `scripts/` — scripts used for demonstrations or testing.
- `screenshots/` — screenshots showing practical evidence.

## Practical Evidence
Screenshots and any scripts used for the exercise should be saved in the appropriate folders. Clearly distinguish between concepts discussed in the case study and features that have actually been configured and tested.

## Conclusion
Distributed and cloud database approaches may help ExpressMall scale as demand grows. Replication, sharding, recovery, security, and consistency must be planned according to the business requirements and tested before production use.
