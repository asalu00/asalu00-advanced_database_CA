
# Portfolio 4: NoSQL and Advanced Data Models

**Course:** MIT 8103 – Advanced Database Systems  
**Academic Session:** 2026/2027  
**Case Study:** ExpressMall Perfume Store

## 1. Introduction

This portfolio explores how a NoSQL database can store and manage product information for the ExpressMall perfume store. MongoDB is selected as the proposed document-oriented database.

## 2. Objectives

- Design a document-based model for perfume products.
- Store perfume data in JSON-like documents.
- Demonstrate product searches and stock updates.
- Evaluate the suitability of document databases for ExpressMall.

## 3. Files and Folders

- `models/perfumes.json` – Sample perfume documents.
- `scripts/mongodb_queries.js` – MongoDB query examples.
- `screenshots/` – Evidence of implementation and testing.
- `portfolio-4-report.md` – Technical explanation and findings.

## 4. Implementation Status

The sample JSON data and MongoDB query script have been prepared. Successful database execution and test results will be documented after they are verified.

## 5. Conclusion

A document-oriented database can support flexible perfume product records and product searches. Its suitability for ExpressMall will be assessed through implementation and testing.
