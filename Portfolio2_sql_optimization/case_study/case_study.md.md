ExpressMall SQL Query Optimisation Case Study
1. Project Overview
This project examines SQL query performance for ExpressMall, a perfume retail business whose PostgreSQL database manages customers, perfume brands, inventory, customer orders, order items, and payments.
2. Business Problem
As the volume of customers, products, orders, and payments increases, database queries may take longer to execute. Inefficient queries and missing or unsuitable indexes can affect the speed of retrieving business information.
3. Project Objectives
- Analyse SQL queries using PostgreSQL execution plans.
- Identify opportunities to improve query efficiency.
- Evaluate the effect of appropriate indexes.
- Compare query execution plans and measured execution times before and after optimisation.
4. Tools and Technologies
- PostgreSQL
- Neon database platform
- SQL
- EXPLAIN ANALYZE
- GitHub for project version control and presentation
5. Methodology
The project will establish baseline query performance, examine execution plans, identify possible bottlenecks, apply appropriate optimisations, and compare the results. Any performance improvement will be reported only when supported by the measurements.
6. Expected Outcome
The project will produce documented SQL queries, execution-plan evidence, a comparison of baseline and optimised performance, and recommendations for maintaining an efficient PostgreSQL database.
