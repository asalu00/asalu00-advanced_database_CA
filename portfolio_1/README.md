
# ExpressMall — Portfolio 1

## Database Design and Modelling

This folder contains the Portfolio 1 deliverables for the ExpressMall perfume shop case study.

### Files

- `case_study.md` — description of the business and database requirements.
- `expressmall_schema.sql` — PostgreSQL table definitions, constraints, and indexes.
- `er_diagram.mmd` — editable source for the entity-relationship diagram.
- `er_diagram.png` — exported ER diagram image.
- `normalisation.md` — explanation of 1NF, 2NF, and 3NF.

### Database platform

PostgreSQL hosted on Neon.tech.
