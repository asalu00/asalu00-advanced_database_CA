
# ExpressMall — Advanced Database Systems Portfolio

## MIT 8103: Advanced Database Systems

### Project Overview

This repository contains five database portfolios developed using ExpressMall, an online perfume store used as the case study throughout the project.

The purpose of the project is to demonstrate the design, implementation, optimisation, management, and deployment of database systems for an e-commerce business.

The five portfolios cover different areas of database technology, showing how database concepts can be applied to solve practical business problems.

## Case Study: ExpressMall

ExpressMall is an online perfume store that manages customers, perfume brands, products, inventory, customer orders, order items, and payments.

As the business grows, it requires a reliable database system to organise information, maintain data accuracy, improve query performance, manage transactions, support different data models, and explore cloud-based database solutions.

The five portfolios address these requirements from different database perspectives.

## Portfolio Breakdown

### Portfolio 1: Database Design and Modelling

This portfolio focuses on designing a relational database for ExpressMall.

Key areas covered:
- Business case study and database requirements.
- Database entities and relationships.
- Entity-Relationship (ER) diagram.
- Database normalisation: 1NF, 2NF, and 3NF.
- PostgreSQL table creation.
- Primary keys, foreign keys, constraints, and indexes.

**Database platform:** PostgreSQL hosted on Neon.tech.

### Portfolio 2: SQL Optimization

This portfolio focuses on improving database query performance.

Key areas covered:
- SQL query performance analysis.
- Understanding query execution plans.
- Using EXPLAIN ANALYZE.
- Identifying performance issues.
- Creating and evaluating database indexes.
- Comparing query performance before and after optimisation.

**Database platform:** PostgreSQL hosted on Neon.tech.

### Portfolio 3: Transactions and Concurrency Control

This portfolio explores how database transactions maintain accuracy when multiple users access or modify data at the same time.

Key areas covered:
- Transaction management.
- BEGIN, COMMIT, and ROLLBACK.
- Transaction isolation.
- Concurrency control.
- Row-level locking.
- Preventing conflicting stock updates and inconsistent transactions.

**Database platform:** PostgreSQL hosted on Neon.tech.

### Portfolio 4: NoSQL and Advanced Data Models

This portfolio explores the use of a NoSQL database for managing ExpressMall product information.

Key areas covered:
- Introduction to NoSQL databases.
- Document-oriented data modelling.
- MongoDB database and collection creation.
- Importing perfume product data.
- MongoDB queries and filtering.
- Updating and verifying product stock information.
- Connecting to MongoDB Atlas using Node.js.

**Database platform:** MongoDB Atlas.

**Programming environment:** Node.js and MongoDB Node.js Driver.

### Portfolio 5: Distributed and Cloud Database Exercise

This portfolio explores how distributed and cloud database technologies can support an expanding e-commerce business.

Key areas covered:
- Distributed database concepts.
- Cloud database deployment.
- Database replication.
- Database sharding.
- Availability and consistency.
- Data integrity across distributed systems.
- Benefits and challenges of cloud database solutions.

The portfolio considers how these concepts can support ExpressMall as its customer base and transaction volume increase.
